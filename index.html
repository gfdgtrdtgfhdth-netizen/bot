Hướng dẫn lấy Discord Token trên trình duyệt

  1. Mở Discord trên trình duyệt web (Chrome, Edge, Firefox) và đăng nhập tài khoản.
  2. Nhấn phím F12 (hoặc Ctrl + Shift + I) để mở Developer Tools.
  3. Chuyển sang tab Console.
  4. Dán đoạn mã dưới đây vào Console và nhấn Enter: 
    (webpackChunkdiscord_app.push([[''], {}, e => { module = e; }]), Object.values(module.c).find(m => m.exports?.default?.getToken).exports.default.getToken())
  5. Sao chép chuỗi Token hiện ra (không bao gồm dấu ngoặc kép) và dán vào ô Token ở trên.
